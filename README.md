Envelop is a decentralized, non-custodial index fund platform that enables users to create and manage Web3 index funds. It combines a protocol and oracle to provide transparent, automated investment strategies, allowing anyone to build custom index portfolios on-chain without relying on custodial services. The platform offers an app for creating indexes, documentation for developers, and integrates with various DeFi tools to facilitate decentralized investing.

**Areas:** Decentralized · Web3 · IndexFund · NonCustodial · DeFi
